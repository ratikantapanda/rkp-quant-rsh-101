# Macro research

This workstream contains macroeconomic research projects, including FRED-based studies, regime analysis, interest rate research, inflation analysis, and macro factor exploration.

## Typical projects
- FRED data pull and validation
- Yield curve and recession signal analysis
- Inflation persistence and activity monitoring
- Macro regime classification
- Macro risk indicators and factor scoring
