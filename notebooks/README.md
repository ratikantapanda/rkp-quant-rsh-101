# Notebooks

This directory is for exploratory research and quick hypothesis testing. Keep notebooks lightweight and clear.

## Naming convention
- `00_...` for templates and setup notebooks
- `01_...` for raw exploratory analysis
- `02_...` for feature and signal testing
- `03_...` for factor or alpha experiments
- `04_...` for strategy or backtest review

## Standards
- Define the question at the top.
- Keep a data contract section.
- Validate the data before modeling.
- Save reusable logic into source files once it proves useful.
- Do not leave notebook code as the only implementation of a serious idea.
